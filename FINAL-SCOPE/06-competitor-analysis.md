# 06 — Competitor Analysis (LegalZoom / ZenBusiness / Bizee)

What we learned from fetching the 3 competitor sites client referenced.

---

## LegalZoom — https://www.legalzoom.com/business/business-formation/

**Homepage approach:** Show entity types as 4 BIG cards with starting prices. Click → straight into wizard.

| Entity | Starting Price |
|---|---|
| LLC | $0 + state filing fees |
| Corporation | $149 + state filing fees |
| Nonprofit | $99 + state filing fees |
| DBA | $99 + state filing fees |

**Wizard flow:** entity → state → name → packages → add-ons → checkout

**Key trust signals on homepage:**
- "Backed by 25+ years of experience and 4M+ formations"
- Trustpilot 5-star reviews scrolling
- "100% Accurate Filing Guarantee"
- Bank/partner logos (Bank of America, Square, WIX)

---

## ZenBusiness — https://www.zenbusiness.com/

**Homepage approach:** Show pricing packages first. AI assistant "Velo" branding everywhere.

| Plan | Price |
|---|---|
| Starter | $0 + state fees |
| Pro | $199 + state fees (renews $199/yr) |
| Premium | $399 + state fees (renews $399/yr) |

**Key features highlighted:**
- "100% accuracy guarantee"
- Trustpilot 4.8 / 28,830 reviews
- "Over 850k+ businesses started"
- 3 simple steps: Select services → File with state → Add growth tools

**Wizard flow:** name → state → package → add-ons → checkout

---

## Bizee — https://bizee.com/ ⭐ MOST SIMILAR TO BIZJUMP

**Client doc explicitly references this:** `https://orders.bizee.com/form-order-now.php?entityType=LLC&entityState=IA`

**Homepage approach:** "Find the entity that's right for you" — tabs for LLC/S-Corp/C-Corp/Nonprofit with comparison info, then 3 packages.

| Plan | Price |
|---|---|
| Basic | $0 + state fee |
| Standard | $199 + state fee |
| Premium | $299 + state fee |

**Wizard layout (the actual order page):**
- Top: Steps shown as chips → "Entity Type: LLC" / "State: Iowa"
- Then a comparison TABLE (not cards) with all features as rows
- Add-ons inline with checkboxes (Expedited filing +$50, Business Contracts +$150, etc.)
- Running total at bottom

**Trust signals:**
- "Founder Led & Independently Owned Since 2004. Over 1,000,000 Entrepreneurs Served!"
- Trustpilot 4.7 / 25,201 reviews
- "Bizee is NOT a law firm" disclaimer

---

## Patterns ALL 3 Use (We Should Too)

✅ Show "+ state fees" everywhere — never combine into one number
✅ Big trust signal: review count + star rating + Trustpilot logo
✅ "Not a law firm" disclaimer at bottom
✅ Processing time mentioned per plan
✅ "Most Popular" badge on middle plan
✅ One-time payment vs subscription clearly separated
✅ Comparison table for plans (Bizee) — better than cards for 4 tiers
✅ Big colorful CTA buttons ("Start now" / "Get Started")
✅ State dropdown with auto-show fee

---

## Patterns We Should AVOID

❌ "Starts at $0" pricing (client explicitly rejects this — it's a hidden-fee tactic)
❌ Forced upsells / pre-checked add-ons that aren't necessary
❌ Aggressive popups
❌ Complicated pricing pages
